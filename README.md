# Wordle Game

## How to Run the Code

1. Open the Command Prompt (CMD) and navigate (`cd`) to the location where you have saved the four Java files.
2. Compile the Java files using the following command:
   ```bash
   javac -d . letterField.java gamePanel.java mainInterface.java Wordle.java
   ```

3. Run the game with this command:
   ```bash
   java Wordle.Wordle
   ```
## How to Play
* The rules are the same as the classic Wordle game.
* You can submit your answers using the CHECK button or the ENTER key.
* A special feature: click the "A little help" button to get assistance.
* If a dialog box appears, interact with it by clicking the available options.

### Important Notes:
* Avoid pressing the TAB key.
  * Pressing TAB may cause focus issues, preventing you from typing letters into the game.
  * If this happens:
    1. Try pressing TAB again to regain focus.
    2. If that doesn't work, exit the game and restart it.

Enjoy the game! 😊
